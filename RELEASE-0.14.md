# Local Gemma Studio 0.14.0

Категории моделей по умолчанию свёрнуты. Раскрытые категории сохраняются при обновлении статуса. Переход к загрузке модели из меню раскрывает её категорию.

Исправлена остановка приватного движка перед установкой GPU-компонентов в Windows. На некоторых системах фильтр Get-NetTCPConnection по состоянию Listen/Established не возвращает нужную запись, хотя Ollama отвечает. Теперь приложение создаёт конкретное соединение, находит его серверный PID по паре портов и проверяет путь исполняемого файла и команду serve. Произвольные процессы по имени не завершаются. Проверка доступна без остановки: `runtime/python/python.exe runtime/compute_probe.py --check-engine runtime/ollama/ollama.exe`.

Это исправление установки компонентов, не расширение аппаратной поддержки ROCm. Radeon RX 470 не входит в поддерживаемые Windows ROCm GPU. Для старых видеокарт остаётся экспериментальный Vulkan, совместимость зависит от драйвера; CPU остаётся рабочим вариантом.

Foundation-Sec 8B Abliterated подключена к чату и агенту: отдельный текстовый формат базовой Llama, JSON-схема вызовов инструментов, проверка формата до выполнения действий. Базовая модель не становится instruction-tuned из-за адаптера; сложные агентные цепочки могут работать хуже специализированных агентов. На уже скачанной Q4 проверено настоящее чтение файла через read_file и возврат точной контрольной строки.

Другой выбранный агент может вызвать `security_analyze`: Foundation-Sec анализирует переданный текст кода, журналов или фактических результатов инструментов. Этот вызов не выполняет скрытых сканирований и возвращает выводы как анализ переданного материала. Приложение не добавляет отдельного фильтра содержания ответов. Общие подтверждения действий, проверка реальных результатов и защита от инструкций внутри документов сохраняются.

Qwen3-Reranker 0.6B Q8 добавлена в категорию «Поиск по смыслу». Используется GGUF ggml-org со специализированной головой ранжирования и настоящий endpoint `/reranking` из комплектного llama.cpp. Результаты поиска сохраняют исходные URL и тексты; меняется только порядок, добавляются оценки. Ранкер работает на CPU в отдельном процессе на время поиска, затем процесс завершается. Веса не скачиваются автоматически. Переключатель находится в настройках интернета. Если ранкер не установлен, недоступен или завершился с ошибкой, сохраняется порядок поисковика с явной диагностикой в результате web_search. Внешняя Ollama без локального файла весов для этого пути не поддерживается. На macOS нужен доступный llama-server; если его нет, поиск продолжает работать без переранжирования.

WebSailor 7B Q4 добавлена в категорию «Веб-исследование». Адаптер разбирает её протокол search/visit, переводит запросы в web_search/fetch_url, извлекает answer и think. Примеры tool_call внутри рассуждений и окончательного ответа не выполняются. Неизвестные/обрезанные вызовы не считаются успешными. URL проходят обычную проверку области задачи. Интеграция проверена на протокольном стенде; сами веса WebSailor не скачивались и качество её ответов здесь не измерено.

Проверенные Abliterated-варианты Qwen3-Reranker 0.6B и WebSailor 7B при поиске не найдены, поэтому добавлены обычные версии. Abliterated-модель общего Qwen 0.6B не подменяет обученный Reranker.

Проверки:

```text
cargo test --locked
runtime/python/python.exe scripts/tests/test_specialist_protocols.py
runtime/python/python.exe scripts/tests/test_model_storage.py
```

Для отдельного теста уже установленной Foundation-Sec: `runtime/python/python.exe scripts/tests/test_foundation_native.py`. Тест не скачивает модель, создаёт свой временный проект и не меняет выбранные пользователем модели.
