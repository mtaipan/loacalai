# Local Gemma Studio 0.13.0

Каталог моделей общий для настроек приложения и установщика. Рекомендованы Index-Translate 2B Q6, Index-Translate 9B Q4 и Qwen3.5 4B Abliterated. По умолчанию в установщике ничего не отмечено. Описания объясняют назначение и ограничения каждой модели.

Для SERA 8B/14B и Antares 1B проверенные Abliterated-варианты не найдены; используются обычные GGUF. Для остальных новых чат-моделей выбраны доступные Abliterated-варианты. Qwen3-Embedding не является чат-моделью. Foundation-Sec и Antares доступны для скачивания и хранения; специализированные адаптеры для них ещё не подключены. Установка модели сама по себе не добавляет её специализированный рабочий процесс в приложение.

У каждой модели есть своя папка загрузки. Дополнительные папки обслуживают отдельные приватные процессы Ollama: веса не копируются временно в основное хранилище и не требуют ссылок между дисками. Процессы запускаются по мере обращения; несколько одновременно загруженных моделей могут потреблять больше памяти. Недоступный диск отображается как ошибка. Перенос существующих моделей не автоматический: удалите модель и скачайте в новую папку. Данные выбора хранятся в `data/model-locations.json`.

Установщик Windows x64 включает CPU-движок Ollama, переносимый Python, библиотеки мультимедиа/браузера и подписанный Microsoft полный офлайн-установщик WebView2. Веса LLM и Whisper не включены. Базовая установка не требует сети; выбранные модели загружаются только после установки компонентов. Дополнительные GPU-пакеты устанавливаются отдельно в настройках. WebView2 — общий компонент Windows, устанавливается Microsoft в системное расположение. Библиотеки браузерной автоматизации включены; для управления страницами нужен установленный Edge/Chrome либо дополнительная установка Chromium в настройках.

Приложение регистрируется в списке установленных программ. Удаление убирает файлы из манифеста установки, сохраняя чаты, настройки, модели и дополнительные GPU-пакеты. Перед обновлением/удалением закройте Studio.

«Аудит моего сайта» включается под полем ввода. Укажите URL разрешённого сайта в текущем сообщении. На этих origin разрешены тестовые значения в формах, каждое изменяющее действие требует подтверждения. За пределами указанной области обычный вход продолжает требовать пользовательские данные. Шаблоны вроде `your_password` не считаются тестовыми данными. Чтение URL возвращает фактические защитные HTTP-заголовки и флаги cookies без значений cookies. Отсутствие заголовка само по себе не доказывает уязвимость. Это ограниченный помощник проверки, а не автоматический пентест-сканер.

macOS: распакуйте исходники и запустите `Start-macOS.command`. Скрипт собирает актуальные исходники, учитывает версию и изменения файлов, не скачивает модели автоматически. Для первой подготовки нужны интернет, Command Line Tools и macOS 14+. На Apple Silicon используется Ollama с Metal. Сборка и запуск на Mac в этой версии не проверены на реальном устройстве.

Проверки для разработчиков:

```text
cargo test --locked
runtime/python/python.exe scripts/tests/test_model_storage.py
runtime/python/python.exe scripts/tests/test_browser_audit.py
```

Тест хранилищ использует поддельный локальный движок и не скачивает модели. Браузерный тест работает на собственном HTTP-стенде и требует Edge/Chrome либо Chromium.
