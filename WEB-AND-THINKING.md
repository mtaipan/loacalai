# Интернет, браузер и рассуждения — 0.12.1

В 0.12.1 исправлены ссылки на элементы формы: они сохраняются после ввода и чтения, пока существует тот же DOM-узел. При его замене оставшиеся действия пакета останавливаются и страница перечитывается; восстановление ограничено двумя попытками. Перед подтверждением и выполнением проверяется сам элемент. Отсутствующие учётные данные и типичные шаблоны останавливают задачу до ввода; агент не должен выдумывать логин или пароль. Время ожидания подтверждения отображается отдельно от времени исполнения успешного веб-действия.

В поле ввода доступны «Сеть» и «Рассуждения». Модель работает локально; поисковые запросы уходят поисковику, а открытие страниц — соответствующим сайтам.

## Как пользоваться

- **Сеть → Авто:** агент может использовать веб-инструменты; явная просьба найти информацию в интернете запускает поиск. Ссылка в запросе позволяет открыть указанный сайт. Авто не является надёжным определителем всех вопросов, требующих актуальных данных.
- **Поиск:** сначала выполняется реальный поиск по текущему сообщению. Затем модель выбирает источники, открывает страницы и отвечает. Карточки различают найденные и открытые источники.
- **Исследование:** запускает поиск и дополнительно инструктирует модель делать несколько запросов, читать независимые источники и сравнивать их. Это управляемый агентный цикл в пределах лимитов, а не отдельная мощная модель. Фактическое число прочитанных страниц видно в действиях; маленькая модель может не выполнить всю стратегию.
- **Выключена:** веб-инструменты не передаются модели и блокируются обработчиком. Это не сетевой экран для отдельно подтверждаемых команд терминала.
- **Рассуждения:** Вкл/Выкл для моделей с таким переключателем, точные именованные уровни — только если Ollama сообщает их в `/api/show`. В 0.16 «Авто» подбирает режим по этапу: для подготовки поискового запроса выбирает false, если /api/show сообщает его поддержку; для остальных этапов обычно использует значение модели по умолчанию. При восстановлении пустой генерации Авто также может выбрать false. Явный выбор пользователя сохраняется. При неизвестных настройках thinking-модели доступно только «Авто». Переводчики используют отдельный режим без рассуждений.

В настройках → «Интернет и браузер» можно выбрать DuckDuckGo с резервом Bing без API-ключа, свой SearXNG с JSON API или Brave Search API со своим ключом. Платные планы автоматически не оформляются. При ограничении поисковика, CAPTCHA, ошибке DNS или отсутствии сети инструмент возвращает реальную ошибку. Гарантировать доступность стороннего поисковика нельзя.

Браузер использует установленный Edge/Chrome; если их нет, кнопка установки скачивает Chromium в `data/cache/browsers`. Библиотека Playwright устанавливается в runtime приложения. Установщик остаётся небольшим: зависимости скачиваются отдельно. На Windows этой машины уже установлен Edge; дополнительный Chromium не потребовался.

Чтобы видеть окно и самостоятельно входить на сайты, включите «Показывать окно браузера» и начните новый чат. Личный профиль и существующие пароли обычного браузера не подключаются. После ручного входа можно попросить агента снова прочитать страницу. CAPTCHA пользователь может пройти в видимом окне; автоматического обхода нет.

## Что умеют веб-инструменты

- `web_search`: реальные заголовки, URL и выдержки, если провайдер их возвращает.
- `fetch_url`: чтение HTTP-текста с удалением скриптов, стилей и шаблонов; статус, заголовок, ссылки, частичное покрытие и продолжение через `offset`. Перенаправление возвращается как `redirect_to`, не выполняется автоматически.
- `browser_open`, `browser_read`: Chromium с JavaScript, текст страницы, фреймы, ссылки и текущие идентификаторы элементов. Работает с `http://localhost:порт`, `127.0.0.1` и явно указанными локальными адресами при работающем сервере, даже без интернета.
- `browser_action`: клик, ввод, выбор значения, ограниченные клавиши, прокрутка, ожидание, назад, вкладки, переключение вкладки и снимок экрана. Клики, ввод, выбор и нажатия клавиш требуют подтверждения. Отказ останавливает цепочку. Произвольного исполнения JS моделью нет.

Браузер сохраняет страницу и cookies в памяти для продолжения в том же чате. Не больше четырёх сессий; при необходимости освобождается самая старая незанятая. Просроченные неактивные сессии очищаются при следующем запросе. Удаление чата и завершение приложения закрывают его браузер. Сессии не восстанавливаются после перезапуска. Если сессия освобождена, сайт нужно открыть заново.

Ссылки разрешаются по URL пользователя и фактически полученной выдаче/страницам. Доступ к частным адресам из чужих страниц ограничен явно указанными пользователем origin; это проверяется и для запросов браузера. Веб-задачи не получают файловые инструменты автоматически. Текст страниц считается данными, а не разрешением на действия.

## Практические пределы

Это браузерный агент, но обещать работу абсолютно с любым сайтом нельзя. Антибот-защита, DRM, закрытые страницы, нестандартные canvas-интерфейсы и недоступные серверы могут мешать. Скачивания отключены. Страница и список элементов читаются с ограничениями; для длинных страниц есть продолжение, прокрутка и повторное чтение. Снимок сохраняется как изображение; он сам по себе не превращает текстовую модель в зрительную.

Рассуждения занимают время и токены. На настоящей Qwen3.5 2B проверены оба режима; в тесте умножения вариант без рассуждений дал неправильный ответ. Наличие инструментов, ссылок или reasoning не гарантирует достоверность вывода модели. Карточки источников подтверждают доступ к страницам, а не каждое утверждение ответа.

Windows проверен. В архив macOS включены эти же исходники, Playwright и сборочные скрипты; нативная проверка на Mac не выполнялась.

## Что взято из официальной документации

Изучались опубликованные интерфейсы продуктов и API; их закрытая внутренняя реализация неизвестна.

- [OpenAI Web search](https://developers.openai.com/api/docs/guides/tools-web-search): поиск, чтение результатов и ссылки на источники. [Computer use](https://developers.openai.com/api/docs/guides/tools-computer-use): отдельный механизм взаимодействия с интерфейсами.
- [Claude Web search](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool) и [Web fetch](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool): отдельные инструменты поиска и загрузки содержимого.
- [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart): ранжированные результаты, извлечение содержимого и несколько запросов.
- [Ollama Thinking](https://docs.ollama.com/capabilities/thinking): `think`, точные поддерживаемые значения и отдельное поле `message.thinking`.
- [Playwright browsers](https://playwright.dev/python/docs/browsers), [SearXNG API](https://docs.searxng.org/dev/search_api.html), [Brave Search](https://api-dashboard.search.brave.com/documentation/quickstart): используемые способы подключения браузера и поисковых провайдеров.

Проверки: Rust unit tests; цепочка браузера на локальном JS-сайте с вводом и кликом, подтверждением и отказом, продолжением между сообщениями, снимком; настоящий поиск DuckDuckGo; настоящая 2B с чтением локального JS и официальной документации из поисковой выдачи; UI, сохранение переключателей и узкий экран; регрессии файлового агента.
