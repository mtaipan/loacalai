# Быстрый запуск


**0.12.1:** агент различает URL, чтение конкретного файла и простое создание на рабочем столе. Реальные папки ОС, алиас `@desktop/имя.txt`, проверка ошибок записи и скрытие нулевого отчёта в обычном чате.

**0.10.0:** DOCX переводится целыми абзацами с проверкой меток форматирования. Прикрепите документ → нажмите на вложение → «Перевести». Таблицы, стили и ссылки сохраняются; разрывы страниц могут сместиться.
**Windows:** закройте прежнее тестовое окно Studio, затем откройте `Start-Windows.bat`. Для браузера — `Start-Web-Windows.bat`.

**Версия 0.9.0:** Ctrl+Shift+O / ⌘+Shift+O — выделить область экрана и перевести через OCR. PDF/DOCX можно прикрепить и нажать на вложение: чтение, страницы, OCR сканов и скачивание перевода. DOCX → DOCX, PDF → Markdown.

**Агент 0.8.0:** шестерёнка → «Поведение агента и чата»: инструкции, параметры, просмотр промпта. Под ответом раскрываются факты инструментов; read_file показывает исходный текст с копированием.

**Вычисления 0.7.0:** шестерёнка → «На чём запускать LLM». CPU / Авто / обнаруженная GPU; 0 потоков — автоматически. Модули GPU скачиваются отдельно. В этом разделе виден переход на CPU при ошибке ускорителя.

**macOS 14+:** перенесите распакованную папку проекта на Mac и откройте `Start-macOS.command`. Первый запуск скачивает зависимости и модели и собирает `.app`; стандартный установщик Apple Command Line Tools может потребовать вашего действия. Mac-сборка подготовлена в исходниках, но здесь не проверена на macOS.

Чат: **http://127.0.0.1:3210**.

**Версия 0.3.2 — выбор моделей:** над полем сообщения выбирается модель текущего режима. Шестерёнка → «Модели для разных задач» задаёт перевод, перевод выделения, агент и чат отдельно. Ниже — каталог с кнопками скачивания, включая тяжёлые модели. Скачайте нужную модель, выберите её и сохраните настройки. Подробности: `MODELS.md`.

**Перевод в любых приложениях:** запустите настольную Studio, в настройках выберите язык перевода. Выделите текст в другом приложении и нажмите **Ctrl+Shift+T** (Windows) / **⌘+Shift+T** (macOS), затем отпустите клавиши. Перевод откроется отдельно. Основное окно можно свернуть; приложение должно оставаться запущенным. На Mac потребуется «Универсальный доступ».

Если приложение не отдаёт выделение, скопируйте текст вручную и используйте «Перевести буфер» на **http://127.0.0.1:3210/quick.html**.

**Поиск файлов:** в настройках по умолчанию включён поиск и чтение на доступных локальных дисках. Например: «Найди файл makar.txt на компьютере и прочитай его». Для нескольких совпадений попросите искать по маске `*makar.txt`. Поиск может завершиться по лимиту времени; это отображается в результате. Запись файлов остаётся в рабочей папке с подтверждением.

- «Агент» — файлы, код и инструменты с подтверждением.
- «Перевод» — выбранный переводчик, языки выбираются над полем сообщения.
- «Чат» — обычный диалог.
- Скрепка / перетаскивание / вставка — картинки, аудио, Markdown и код.
- Микрофон — голосовой ввод с проверкой текста перед отправкой.
- Стрелка загрузки сверху — экспорт диалога в `.md`.
- Шестерёнка — рабочая папка, темы, модели и параметры.

На этом Windows-компьютере сохраняйте прежнюю папку `TranslateGemma` рядом с `LocalGemmaStudio`: из неё повторно используются модели и Python. Архив для переноса не содержит ваших чатов, вложений, Python-окружения и многогигабайтных моделей; на новом компьютере они устанавливаются при первом запуске.

Подробности и ограничения — в `README.md`.
