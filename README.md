# Local Gemma Studio

Локальный чат и настольное приложение на Rust: перевод текста и документов, агент с инструментами, веб-поиск, браузер, OCR и распознавание речи. Модели запускаются через Ollama; история и настройки хранятся на вашем компьютере.

**Windows x64:** скачайте офлайн-установщик `LocalGemmaStudio-Setup-0.14.0.exe` из [GitHub Releases](https://github.com/mtaipan/loacalai/releases/latest). Компоненты включены; интернет нужен только для необязательной загрузки выбранных моделей и дополнительных GPU-пакетов. По умолчанию используется `A:\LocalGemmaStudio`, если диск существует. Приложение и каждую модель можно разместить в своей папке.

**0.14.0:** исправление установки GPU-компонентов Windows, сворачиваемые категории, адаптер Foundation-Sec, WebSailor и подключение Qwen3-Reranker. [Изменения и ограничения](RELEASE-0.14.md).

**0.14.1 (исходники):** убран отдельный переключатель аудита сайта. Запрос на проверку безопасности с URL задаётся в обычном чате агента; продолжение проверки сохраняет адрес текущего сайта. Действия в браузере по-прежнему показываются перед подтверждением.

## Сборка из исходников

Нужен Rust stable. На Windows для сборки Rust необходимы Visual Studio Build Tools с инструментами C++; для работы настольного окна — WebView2 Runtime. На macOS нужны Xcode Command Line Tools; текущий runtime рассчитан на macOS 14 и новее. Работа на Mac нативно не проверялась.

```powershell
git clone git@github.com:mtaipan/loacalai.git
cd loacalai
cargo build --release --locked
Copy-Item target/release/local-gemma-studio.exe LocalGemmaStudio.exe
.\Start-Windows.bat
```

На Mac запустите `Build-macOS.command`, затем `Start-macOS.command`; для DMG — `Build-DMG-macOS.command`. Скрипты загружают необходимые компоненты отдельно.

Для сборки Windows-установщика после сборки приложения выполните `python scripts/package_release.py` в Windows с установленным .NET Framework. Результаты появятся в `dist/`.

В Git не включены модели, runtime, переписка, настройки, кеши и готовые бинарники. Проверки Rust: `cargo test --locked`; сборка серверного варианта: `cargo check --no-default-features --locked`. Переводческие модели и модели агента выбираются отдельно; небольшая локальная модель может ошибаться в ответах и действиях.

Локальный чат с веб-интерфейсом и настольным приложением на Rust. Общий интерфейс для нескольких локальных переводчиков, агента, распознавания картинок и речи. Модели для разных задач выбираются независимо.

## Документы и область экрана — версия 0.9.0

**Область экрана:** откройте нужное приложение и нажмите Ctrl+Shift+O / ⌘+Shift+O, выделите прямоугольник. Esc отменяет выделение. Перевод откроется отдельно. Сочетание меняется в настройках; на Mac нужна запись экрана. В режиме исходного языка «Авто» OCR использует English; для русского текста выберите русский. Обычное выделение текста по-прежнему переводится через Ctrl+Shift+T / ⌘+Shift+T.

**PDF/DOCX:** прикрепите файл и нажмите на него. В окне можно читать, выбирать 1–5 страниц PDF, включать OCR сканов, переводить и скачивать результат. DOCX экспортируется в DOCX с сохранением таблиц, стилей и вложенных изображений; перевод отдельных фрагментов может терять контекст, число страниц может изменяться. PDF экспортируется в Markdown по страницам. Текст внутри изображений DOCX не переводится. Исходное вложение сохраняется. Один документ без подписи в режиме «Перевод» также возвращает файл результата в чат.

Агент использует read_document и translate_file для этих форматов. Лимиты: файл 80 МБ; перевод DOCX до 300 фрагментов / 40000 символов; PDF до 40000 символов в диапазоне. Подробные ограничения и проверки — RELEASE-0.4.md.

**Сборка DMG:** на Mac откройте Build-DMG-macOS.command. Образ содержит приложение и исходники, runtime/модели скачиваются отдельно. Сам DMG и нативная работа новых функций на Mac из Windows не проверялись.

## Агент — версия 0.8.0

В настройках → «Поведение агента и чата» доступны дополнительные инструкции, температуры и штраф повторов. «Показать системный промпт и шаблон» читает сохранённые настройки и метаданные Ollama. Внутри ответа раскрывается «По инструментам»: проверенные файловые изменения, статусы и команды. В карточке read_file доступен исходный текст с копированием.

При явном противоречии успешному файловому действию выполняется одна перепроверка ответа по результатам; оставшееся противоречие отмечается. Это ограниченная проверка фраз, а не гарантия истинности. Веса модели и их обучение не меняются. Мат и критика в файлах приложением не фильтруются. Небольшие модели по-прежнему могут неверно понимать запрос или менять пунктуацию: перед разрешением записи проверьте предпросмотр. Для буквального содержимого выделяйте его отдельным блоком кода и указывайте, входят ли завершающие знаки и переводы строк. Подробности проверок и оставшихся этапов — в RELEASE-0.4.md.

## Вычисления — версия 0.7.0

Шестерёнка → «На чём запускать LLM»: автоматический выбор, CPU, NVIDIA CUDA, AMD ROCm или Vulkan для совместимых NVIDIA/AMD/Intel. Конкретная карта выбирается по обнаруженному устройству для CUDA и Vulkan; ROCm и Metal выбирают устройство автоматически. Потоки CPU: 0 — выбор движка, либо число до количества логических процессоров. Убрано прежнее фиксированное значение 6.

На macOS 14+ Apple Silicon (M1 и новее) доступны CPU и Metal; Intel Mac работает на CPU. Память Apple Silicon общая. Поддержка конкретного GPU зависит от модели, драйвера и Ollama: это не обещание работы на любой видеокарте. На Windows GPU-модули скачиваются отдельно в runtime/ollama, без увеличения небольшого установщика. Модели и временные файлы остаются в папке приложения, по умолчанию A:\LocalGemmaStudio.

Резервный режим CPU включается при ошибке запуска ускорителя или вычисления. Причина сохраняется и показывается в настройках; можно отключить резервирование либо повторить подготовку устройства. Уже начавшийся ответ не повторяется автоматически, чтобы не дублировать текст. Фактическое размещение берётся из Ollama после загрузки модели; объём памяти GPU не является процентом загрузки GPU. Выбор относится к LLM, а не OCR/Whisper.

На Ryzen 5600X/Radeon RX 470 проверен реальный сбой Vulkan при старте → переход на CPU → успешный ответ Qwen3.5 2B; также смена режима и потоков CPU. GPU-ускорение на RX 470 с текущим движком не заработало. NVIDIA, Intel GPU и macOS физически здесь не проверялись. Источники ограничений: https://docs.ollama.com/gpu и https://docs.ollama.com/macos.

## Выбор модели

Нажмите на название модели справа над полем сообщения: откроется меню выбора текущего режима. Галочка отмечает выбранную модель, пункт «Другие модели» открывает остальные варианты и установку. В настройках отдельно задаются основной переводчик, переводчик выделения, агент и чат. Каталог показывает установленные модели и предлагает скачать остальные по одной. Подробности, размеры и источники — в [MODELS.md](MODELS.md).

Практические кандидаты: Index-Translate 2B Q6 для быстрого перевода, Hy-MT2 7B Q4 для более тяжёлого перевода, Qwen2.5 7B для агента. Прежние TranslateGemma 4B / Qwen2.5 3B остаются доступны. Есть выбор TranslateGemma 12B/27B, Index 9B и Qwen2.5 14B. Тяжёлые модели требуют больше RAM и на CPU отвечают медленнее; превосходство на каждом тексте не гарантируется.

## Запуск на Windows

Откройте `LocalGemmaStudio.exe`. Он сам запускает локальный сервер и интерфейс. Установщик — `dist/LocalGemmaStudio-Setup.exe`, папка по умолчанию `A:\LocalGemmaStudio`. Все модели, чат, кэш, переносимые Python и Ollama находятся в этой папке. В настройках модели можно скачивать и удалять. Подробнее — [RELEASE-0.4.md](RELEASE-0.4.md).

Для нового компьютера установщик скачивает runtime отдельно, без установки Python/Ollama в системные папки. Веса LLM скачиваются через каталог моделей. Веб-версия: http://127.0.0.1:3210. Дополнительный BAT для браузера сохранён как удобный вариант.

## Запуск на macOS

Распакуйте комплект в отдельную папку и откройте **Start-macOS.command**. Для браузера — **Start-Web-macOS.command**. Для остановки — **Stop-macOS.command**.

Скрипт предназначен для macOS 14+ на Apple Silicon и Intel. Он подготавливает Python, OCR через Apple Vision, Whisper, Ollama и собирает Rust-приложение под текущий Mac. После первой сборки появляется `Local Gemma Studio.app`; её можно открывать как обычное приложение, сохраняя всю папку проекта рядом.

Если не установлены Apple Command Line Tools, первый запуск вызовет штатный установщик Apple. Завершите установку и снова откройте `.command`. Установка инструментов и разрешение микрофона могут требовать вашего действия. Приложение не подписано сертификатом Apple и не нотарифицировано.

**macOS здесь не запускалась: подготовлены исходники, системный OCR, сборка `.app` и стартовые скрипты; их реальную работу необходимо проверить на Mac.** В комплекте нет готового macOS-бинарника. Синтаксис shell-скриптов проверен на Windows через bash.

Если при переносе файлов потерялся признак исполняемости, выполните из папки проекта:

```bash
chmod +x *.command scripts/*.sh
./Start-macOS.command
```

## Перевод выделенного текста во всей системе (0.2.1)

1. Запустите настольное приложение через `Start-Windows.bat` или `Start-macOS.command`.
2. В настройках откройте «Перевод выделения в любых приложениях»: выберите язык перевода и при необходимости исходный язык. По умолчанию исходный определяется автоматически.
3. Выделите копируемый текст в браузере, редакторе или другом приложении. Нажмите **Ctrl+Shift+T** на Windows или **⌘+Shift+T** на macOS и отпустите клавиши.
4. Перевод появится в отдельном окне; его можно скопировать. Следующее выделение переводится тем же сочетанием. Сочетание меняется в настройках (`Control+Shift+T`, `Super+Shift+T` и т. п.).

Основное окно можно свернуть. Закрытие настольного приложения выключает глобальную горячую клавишу; одного веб-сервера для неё недостаточно. Это перевод в отдельном окне, без автоматической подмены текста в исходном приложении.

Захват использует стандартное копирование выделения и затем восстанавливает обычные форматы прежнего буфера. Приложения без поддержки копирования, защищённые поля и окна с повышенными правами могут не отдать текст. В таком случае скопируйте его вручную, откройте `http://127.0.0.1:3210/quick.html` и нажмите «Перевести буфер». Для текста на картинке используйте вложение с OCR в чате.

На macOS разрешите приложению «Универсальный доступ» в системных настройках конфиденциальности для отправки ⌘+C. Права выдаются вами в штатном диалоге macOS. На реальном Mac эта функция здесь не проверялась.

Проверены регистрация глобального сочетания на Windows, определение исходного языка, перевод через API с выбором целевого языка из настроек и поиск/чтение агентом тестового файла вне рабочей папки. Полная цепочка захвата выделения горячей клавишей пока не проверена в пользовательских приложениях.

## Режимы чата

| Режим | Назначение |
|---|---|
| Агент | Вопросы, работа с файлами, поиск, код и команды. Выбранная модель агента вызывает инструменты, выбранный переводчик переводит. |
| Перевод | Прямой перевод через выбранную переводческую модель. Языки выбираются над полем ввода. Большой текст разбивается на части. |
| Чат | Обычный диалог с выбранной моделью чата без инструментов. Вложения предварительно распознаются. |

Если прикрепить картинку или аудио без сообщения в режиме агента/чата, приложение показывает распознанный текст. Чтобы перевести вложение, выберите «Перевод» либо напишите явный запрос. Изображения читаются через OCR: это извлечение текста, а не описание объектов на фото.

## Вложения и буфер обмена

- Прикрепляйте несколько файлов кнопкой скрепки, перетаскиванием или вставкой.
- `Ctrl+V` / `⌘+V` поддерживает текст и картинки. Кнопка вставки также использует системный буфер через Rust, включая скопированные файлы из Проводника/Finder.
- Прочие форматы буфера преобразуются в обычный текст, если он доступен. Вставка не запускает команды автоматически.
- Картинки: PNG, JPEG, WebP, BMP, TIFF. Windows: установленные языки OCR, здесь русский и английский; macOS: Apple Vision.
- Аудио: WAV, MP3, M4A, OGG, FLAC, WebM, Opus и форматы декодера FFmpeg. Многоязычная Whisper Small работает на CPU.
- Текст UTF-8: `.md`, `.txt`, `.rs`, `.py`, `.js`, `.ts`, `.json`, `.toml`, `.yaml`, `.csv`, `.srt` и другие исходники. Markdown отображается с таблицами, списками и подсветкой кода.
- До 12 вложений на сообщение, до 80 МБ на файл; текстовое вложение — до 500 КБ. Большие задачи могут упереться в контекст модели: разбивайте их на части.
- PDF, DOCX и бинарные офисные файлы пока не имеют встроенного извлечения текста. Сохраните нужную страницу картинкой или экспортируйте в UTF-8.

## Голос

Нажмите микрофон. «Начать запись» использует микрофон браузера/WebView; «Остановить» завершает запись и распознаёт её. Вставляйте результат в сообщение после проверки. Сообщение не отправляется автоматически.

Если запись в WebView недоступна, используйте «Системный микрофон»: это запись через Python/sounddevice на выбранные в настройках 10–60 секунд. Её также можно остановить. Понадобится штатное разрешение ОС на микрофон. Микрофон не включается при открытии приложения.

## Работа агента

Укажите абсолютный путь к рабочей папке в настройках. Панель справа показывает файлы проекта; нажатие добавляет путь в поле запроса.

Инструменты: `list_files`, `read_file`, `search_files`, `write_file`, `translate_text`, `translate_file`, `read_image`, `transcribe_audio`, `record_microphone`, `run_command`.

Примеры:

```text
Прочитай README.md и объясни, как запустить проект.
Найди TODO в исходниках.
Создай notes.md с кратким описанием проекта.
Переведи input.txt с английского на русский и сохрани output.ru.md.
Распознай текст в screenshot.png и переведи его на английский.
Расшифруй meeting.mp3 на русском.
```

Перед записью файла, запуском команды или записью микрофона агент показывает карточку подтверждения с аргументами. Отказ блокирует действие. Через 5 минут без ответа запрос закрывается. На реплику разрешено до 12 вызовов инструментов.

При включённом «Искать и читать файлы на всём компьютере» поиск по имени и чтение доступны на локальных дисках с правами вашей учётной записи. Агент сначала вызывает find_files, затем читает найденный абсолютный путь. Точное имя возвращает первое совпадение; для списка совпадений используйте маску, например `*makar.txt`. Поиск ограничен временем (по умолчанию 120 секунд, максимум 300), 2,5 млн записей и 100 результатами; неполный поиск явно помечается и не означает, что файла нет. Недоступные ОС каталоги и ссылки пропускаются. Поиск по содержимому search_files остаётся в рабочей папке. Если выключить доступ ко всему компьютеру, чтение тоже ограничивается рабочей папкой. Запись через файловые инструменты всегда ограничена рабочей папкой, включая проверку ссылок. Разрешённая команда работает с правами вашего пользователя: Windows PowerShell / macOS `/bin/sh`. Она может обращаться и вне папки; это не песочница. Маленькая Qwen может ошибаться в планировании, поэтому проверяйте предлагаемые действия.

## История и Markdown

Над ответом отображается «Работал …» с общим временем запроса. Во время выполнения счётчик обновляется каждую секунду. Итог измеряется сервером и сохраняется в истории, в том числе при остановке или ошибке. Время включает обработку вложений, инструменты и ожидание подтверждений. Для старых сообщений без сохранённого замера время не придумывается.

- История сохраняется на диске и доступна после перезапуска.
- В боковой панели: поиск, переименование и удаление диалогов.
- Верхняя кнопка загрузки экспортирует чат в `.md`; у каждого ответа также есть сохранение и копирование.
- Код копируется отдельной кнопкой. Последний ответ можно перегенерировать.
- Редактирование сообщения подставляет его текст в новый запрос и сохраняет прежнюю историю.
- В экспорт включаются тексты и названия вложений; сами вложения остаются в `data/uploads`.
- Есть тёмная/светлая темы и оформление по системной теме.

Горячие клавиши: Enter — отправить, Shift+Enter — новая строка, Ctrl/⌘+K — поиск чатов, Ctrl/⌘+N — новый чат, Esc — остановить ответ.

```text
src/                           Rust: HTTP API, агент, инструменты, SSE, хранение, окно
web/                           Общий интерфейс; все библиотеки включены локально
runtime/                       Изолированный Python OCR/Whisper-worker
scripts/                       Установка, запуск и остановка
data/chats/                    JSON-история чатов
data/uploads/                  Вложения и записи браузерного диктанта
data/workspace/                Рабочая папка по умолчанию
data/settings.json             Настройки
data/logs/                     Журналы
data/models/                   Модели Ollama при отдельной установке
```

Удаление чата удаляет JSON диалога, но не очищает автоматически сохранённые вложения. Данные для переноса/резервной копии — папка `data`; закрывайте задачи перед копированием. История хранится без дополнительного шифрования, с обычными правами вашей учётной записи.

Сервер Studio слушает только `127.0.0.1:3210`, отдельная Ollama — `127.0.0.1:11435`. Интернет нужен для первоначального скачивания, установки/обновления и явно разрешённых сетевых команд. Облачные API-ключи не требуются. После подготовки модели работают офлайн. В коде интерфейса нет CDN, аналитики или внешних шрифтов.

Сервер и агент написаны на Rust (Axum/Tokio/reqwest), настольное окно — Wry/Tao. Python используется только отдельным процессом для существующего OCR/Whisper и микрофона; это не полностью Rust-реализация распознавания. Ollama выполняет сами языковые модели.

Базовые модели: TranslateGemma 4B Q4_K_M (~3,3 ГБ), Qwen2.5 3B Q4_K_M (~1,9 ГБ), Whisper Small (~486 МБ). На Windows по умолчанию включён CPU-режим из-за обнаруженного сбоя Vulkan на RX 470. На Mac Ollama может использовать Metal; распознавание речи настроено на CPU.

## Сборка из исходников

```bash
cargo test --locked
cargo build --release --locked
# Только сервер, без зависимостей оконного приложения:
cargo build --release --no-default-features --locked
```

Windows: Rust MSVC и Visual Studio C++ Build Tools нужны только для самостоятельной сборки. macOS: Rust и Apple Command Line Tools; стартовый скрипт готовит Rust при необходимости.

После изменения `web/` пересоберите бинарник: ресурсы встроены в приложение. На Windows можно вызвать `scripts/start-windows.ps1 -Rebuild` при остановленном приложении.

Переменные окружения:

| Переменная | Значение |
|---|---|
| `LOCAL_GEMMA_HOME` | Папка приложения и данных |
| `LOCAL_GEMMA_PORT` | Порт Studio, по умолчанию 3210 |
| `LOCAL_GEMMA_OLLAMA` | Адрес уже запущенной Ollama, по умолчанию `http://127.0.0.1:11435` |
| `LOCAL_GEMMA_OLLAMA_BIN` | Путь к исполняемому файлу Ollama |

При переопределении адреса Ollama запустите указанный сервер самостоятельно. Обычные скрипты используют локальные адреса по умолчанию.

## Проверка и ограничения

Windows: сборка Rust и настоящее окно WebView2 проверены. Интеграционные проверки покрывают перевод с потоковой выдачей, чтение/запись агентом, отказ в записи, загрузку картинки и аудио, OCR, Whisper, Markdown-вложения, сохранение истории и отмену ответа. Отдельно проверены границы файловых путей и защитный токен запросов. macOS — подготовлена, но без проверки на реальном Mac.

Качество ответов определяется локальными моделями. Это рабочая локальная оболочка со своим набором функций; внешние сервисы, встроенный интернет-поиск, GitHub-аккаунты и расширения Claude Code/Codex не подключены.
